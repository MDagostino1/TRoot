# [TROOT] Secondary Growth and Exodermal Barriers Shape Local Root Hydraulics: Modeling Insights in Tomato
Marco D’Agostino, Rémy Schoppach, Adrien Heymans, Valentin Couvreur, Guillaume Lobet

The analysis is decomposed in 3 notebooks :
- TROOT_GRANAR-MECHA : Load and process anatomical measurements, then run GRANAR-MECHA to evaluate hydraulic features kr and kx
- TROOT_ANALYSIS : Perform statistical analyses and plots on generated hydraulic features.
- TROOT_CRB-MARSHAL : Load root system architectures generated with CRootBox, apply generated hydraulic features and run MARSHAL.
